## Questões

### 1. Descreva o que é HTML

HTML é uma linguagem utilizada pra estruturar o conteudo de uma pagina, definindo os elementos da pagica (titulo, paragrafos, imagens, links, tabelas, etc) por meio de TAGS. o HTML é o esqueleto do site.

---

### 2. Descreva o que é CSS

CSS é uma linguagem utilizada para definir o estilo e os layouts de uma pagina HTML, alterando cores, aparencias, fontes, tamanhos, posicionamento e outros aspectos.

---

### 3. Descreva o que é DOM

o DOM é uma representacao em forma de arvore do conteudo HTML da pagina web, onde cada elemento é tratado como um nó que é acessado e manipulado com JAVASCRIPT.

---

### 4. Descreva o que é um servidor

Um servidor é um sistema/computador que fornece recursos e dados para outros dispositivos. Na web os servidores hospedam sites que respondem as solicitacoes dos clientes.

---

### 5. Descreva o que é HTTP

HTTP é o protocolo de comunicacao entre o servidor e o cliente, definindo como as mensagens sao enviadas e recebidas, quando acessamos um site o navegador requer o HTTP e o servidor devolve uma resposta com o conteudo solicitado. 

---

### 6. Descreva o que é uma API REST

Uma API REST é um conjunto de regras que permite a comunicacao entre diferentes sistemas usando o protocolo HTTP, organizando os dados em recursos e utilizando diferentes metodos (GET, POST, etc) para interagir com esses recursos. 

---

### 7. Descreva o que é JSON e sua relação com APIs REST

JSON é um formato leve de troca de dados que possui uma facil escrita e leitura. Sua relacao com APis REST esta no envio e recepcao de dados entre cliente e servidor, por exemplo ao buscar uma lista de usuarios ou enviar informacoes de um formulario.

---

### 8. Descreva o que é autenticação e autorização

Autenticacao é o processo de verificar a identidade de um usuario e a Autorizacao é o processo de definir as permissoes daquele usuario apos a autenticacao.
